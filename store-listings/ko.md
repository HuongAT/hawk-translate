Hawk Translate는 Edge용 빠르고 방해 없는 번역 및 언어 학습 도우미입니다. 어떤 웹사이트의 어떤 텍스트든 하이라이트하면 즉각적인 번역, 자연스러운 목소리의 발음, 그리고 단어 하나일 경우 어휘를 늘리기 위한 문법과 동의어를 얻을 수 있습니다.

할 수 있는 일
선택하고 번역하기. 텍스트를 하이라이트하면 작은 말풍선이 선택 영역 바로 옆에 번역을 표시합니다.
듣기. 🔊 스피커를 클릭하면 원문이나 번역을 자연스러운 목소리로 들을 수 있습니다. 같은 텍스트를 두 번 클릭하면 더 느리게 반복되어 발음 연습에 좋습니다.
어휘 익히기. 단어 한 개를 선택하면 Hawk가 그 품사(명사 / 동사 / 형용사…)와 동의어를 보여 주어, 단어 가족 전체를 한눈에 볼 수 있습니다.
전체 텍스트 팝업. 툴바 아이콘을 클릭해 아무 텍스트나 입력하거나 붙여넣고, 대상 언어를 고른 뒤 번역하세요.
우클릭 메뉴. 어떤 선택이든 우클릭으로 번역 — 마우스를 멀리 옮길 필요가 없습니다.
여러 번역 백엔드 — 키 불필요
Hawk Translate는 설정 없이 바로 작동합니다. 옵션에서 원하는 서비스를 선택하세요:

Google — 무료, 기본, 빠르고 품질 높음
MyMemory — 무료, 키 불필요, 하루 약 5,000단어
DeepL — 본인의 무료 키 사용 (월 50만 자)
Microsoft Azure Translator — 본인의 무료 키 사용 (월 200만 자)
LibreTranslate — 오픈 소스; 자체 엔드포인트 설정 가능
선택한 백엔드가 실패하면 인라인의 "다른 서비스로 시도…" 선택기가 설정으로 들어갈 필요 없이 즉시 다른 제공자로 재시도합니다.

언어 학습자를 위한 설계
원문과 번역 양쪽에 스피커가 있어 소스 언어를 이해하는 것뿐 아니라 들을 수도 있습니다.
"단어 가족" 패널은 뉘앙스를 보여 줍니다. 품사별로 묶인 동의어를 보는 것이 평이한 번역보다 어휘를 더 빨리 키웁니다.
방해되지 않는 작고 집중된 UI.
사용자 설정
테마: 팝업과 말풍선용 자동 / 밝게 / 어둡게.
말풍선 스타일: 클래식(작게) 또는 카드(원문과 번역 각각 자체 스피커 포함).
자동 닫기: 말풍선은 몇 초 후에 자동으로 사라집니다 — 마우스를 올리면 일시 정지. 0(끔)부터 120초까지 설정 가능.
말풍선 표시 시점: 클릭하는 작은 매 아이콘, 선택 즉시, 또는 팝업/우클릭에서만.
지원 언어
50개 이상의 번역 언어 — 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어(간체 및 번체), 아랍어, 힌디어, 베트남어, 태국어, 터키어, 인도네시아어, 우크라이나어, 폴란드어, 네덜란드어 등. 확장 메타데이터는 20개 언어로 현지화되어 있습니다.

개인정보 보호
Hawk Translate는 개발자에게 어떤 개인 데이터도 수집하거나 전송하지 않습니다. 번역하는 텍스트는 사용자가 선택한 제공자(Google, MyMemory, DeepL, Azure 또는 LibreTranslate)에게만 전송됩니다. DeepL, Azure 또는 LibreTranslate를 위해 입력한 API 키는 브라우저 내에 로컬로 저장되며, 사용자의 요청을 위해 해당 제공자의 자체 서버로만 전송되며 다른 어디에도 전송되지 않습니다.
