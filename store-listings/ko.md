Hawk Translate는 빠르고 방해 없는 번역 및 언어 학습 도우미입니다. 어떤 웹사이트에서든 텍스트를 선택하면 즉시 번역과 자연스러운 목소리의 발음을 확인할 수 있고, 단어 하나를 선택했을 때는 어휘를 늘릴 수 있도록 문법과 동의어까지 보여 줍니다. YouTube, Netflix, Prime Video를 두 가지 자막 언어로 동시에 시청하세요. 남기고 싶은 단어를 저장하고 내장 플래시 카드로 학습할 수 있습니다.

할 수 있는 일
이중 자막으로 YouTube, Netflix, Prime Video를 시청하세요. 플레이어에 새로 추가된 버튼을 누르면 두 줄의 자막이 동시에 표시됩니다 — 위에는 영상의 언어, 아래에는 사용자의 언어입니다. YouTube에서는 두 줄 모두 YouTube 자체 자막(YouTube의 자동 번역 포함)에서 가져와 줄 단위로 정확히 동기화됩니다. Netflix와 Prime Video에서는 해당 작품에 이미 포함된 두 가지 자막 언어를 짝지을 수 있고(타이밍이 완벽하며 어떤 데이터도 페이지 밖으로 나가지 않습니다), 원하는 제공자로 원본 트랙을 사용자 언어로 기계 번역할 수도 있으며, 언어가 하나뿐인 작품이라면 직접 자막 파일(.srt, .vtt, .ttml)을 불러올 수도 있습니다. 기계 번역된 줄은 점진적으로 나타나며 작품별로 캐시되므로, 다시 볼 때는 번역을 다시 하지 않습니다. 광고가 포함된 Prime 스트림에서도 광고 구간을 지나 자막 동기화가 유지됩니다. 자막 줄은 그 자리에서 크기를 조절할 수 있고, 선택한 언어 조합은 기억되어 다음 영상에서 자동으로 적용됩니다. 일시 정지 후 자막의 단어를 선택하면 번역하거나 ☆로 저장할 수 있어 — 자막이 곧 학습 자료가 됩니다.
선택하고 번역하기. 텍스트를 하이라이트하면 작은 말풍선이 선택 영역 바로 옆에 번역을 표시합니다.
듣기. 🔊 스피커를 클릭하면 원문이나 번역을 자연스러운 목소리로 들을 수 있습니다. 같은 텍스트를 두 번 클릭하면 더 느리게 반복되어 발음 연습에 좋습니다.
어휘 익히기. 단어 한 개를 선택하면 Hawk가 그 품사(명사 / 동사 / 형용사…)와 동의어를 보여 주어, 단어 가족 전체를 한눈에 볼 수 있습니다.
단어 저장하고 플래시 카드로 복습하기. 번역 결과의 ☆를 탭하면 학습 목록에 추가됩니다. 간격 반복 방식으로 단어를 복습할 수 있습니다 — 잘 아는 단어는 점점 덜 자주 나오고, 자주 틀리는 단어는 곧바로 다시 나오며, 완전히 익힌 단어는 복습 순환에서 제외됩니다. 학습 목록은 언제든 Anki, CSV, JSON으로 내보낼 수 있습니다.
로컬 기록 보관하기. 모든 번역 내용이 기기에 저장되어 검색하거나, 사이트와 날짜별로 필터링하거나, 내보낼 수 있습니다. 보관 기간은 직접 정할 수 있고, 완전히 꺼둘 수도 있습니다.
전체 텍스트 팝업. 툴바 아이콘을 클릭해 아무 텍스트나 입력하거나 붙여넣고, 대상 언어를 고른 뒤 번역하세요.
우클릭 메뉴. 어떤 선택이든 우클릭 메뉴에서 번역하세요 — 마우스를 멀리 옮길 필요가 없습니다.
키보드 단축키. 단축키를 지정해 현재 선택 영역을 즉시 번역할 수 있습니다 — 말풍선을 꺼둔 페이지에서도 사용할 수 있습니다.
PDF 번역하기. 설정에서 옵션을 켜면 웹의 PDF를 내장 뷰어로 열어, 일반 웹페이지와 마찬가지로 PDF에서도 선택 후 번역 기능을 사용할 수 있습니다.

여러 번역 백엔드 — 키 불필요
Hawk Translate는 설정 없이 바로 작동합니다. 옵션에서 원하는 서비스를 선택하세요:

Google — 무료, 기본, 빠르고 품질 높음
MyMemory — 무료, 키 불필요, 하루 약 5,000단어
DeepL — 본인의 키 사용 (무료 또는 유료 플랜)
Microsoft Azure Translator — 본인의 무료 키 사용 (월 200만 자)
LibreTranslate — 오픈 소스; 자체 엔드포인트를 지정할 수 있습니다
선택한 백엔드가 실패하면 내장된 "다른 서비스로 시도" 선택기가 설정으로 이동할 필요 없이 즉시 다른 제공자로 재시도합니다.

언어 학습자를 위한 설계
YouTube, Netflix, Prime Video의 이중 자막은 자막이 있는 모든 영상을 듣기 연습 교재로 바꿔 줍니다 — 원어를 듣고, 두 언어를 동시에 읽고, 플레이어를 벗어나지 않고도 모르는 단어를 저장할 수 있습니다.
원문과 번역 양쪽에 스피커가 있어 뜻을 읽으면서 원어 발음도 들을 수 있습니다.
"단어 가족" 패널은 뉘앙스를 보여 줍니다 — 품사별로 묶인 동의어를 보면 단순한 번역보다 어휘력을 훨씬 빠르게 키울 수 있습니다.
플래시 카드 복습은 웹을 둘러보다 실제로 마주친 단어를 장기 기억 어휘로 바꿔 줍니다 — 별도의 앱도, 계정도 필요 없습니다.
방해되지 않는 작고 집중된 UI.

사용자 설정
테마: 팝업과 말풍선에 적용되는 자동 / 밝게 / 어둡게.
말풍선 스타일: 클래식(간결한 형태) 또는 카드(원문과 번역이 각각 스피커와 함께 표시됨).
자동 닫기: 말풍선이 몇 초 후 자동으로 사라집니다 — 마우스를 올리면 일시 정지됩니다. 0초(끄기)부터 120초까지 설정할 수 있습니다.
말풍선이 나타나는 시점: 클릭 가능한 작은 매 아이콘, 선택 즉시, 또는 팝업/우클릭을 통해서만.
사이트별 설정: 우클릭 메뉴에서 바로 원하지 않는 사이트의 말풍선을 끌 수 있습니다.

지원 언어
50개 이상의 번역 언어를 지원합니다 — 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어(간체 및 번체), 아랍어, 힌디어, 베트남어, 태국어, 터키어, 인도네시아어, 우크라이나어, 폴란드어, 네덜란드어 등. 확장 프로그램 메타데이터는 20개 언어로 현지화되어 있습니다.

개인정보 보호
Hawk Translate는 개발자에게 어떠한 개인 데이터도 수집하거나 전송하지 않습니다. 번역하는 텍스트는 사용자가 선택한 제공자(Google, MyMemory, DeepL, Azure, LibreTranslate)에게만 전송됩니다. 이중 자막은 현재 보고 있는 영상에 대해 YouTube, Netflix, Prime Video가 이미 제공하는 자막을 읽어 오는 것으로, 두 줄이 모두 영상 자체의 자막 트랙에서 나온 경우에는 번역 제공자가 전혀 개입하지 않으며 해당 데이터는 브라우저 밖으로 나가지 않습니다. Netflix나 Prime Video에서 기계 번역 옵션을 선택하면 자막 텍스트가 다른 번역과 마찬가지로 선택한 번역 제공자에게 전송되며, 그 결과는 사용자의 기기에만 캐시됩니다. 번역 기록, 저장한 단어, 플래시 카드 진행 상황은 오직 사용자의 기기에만 저장되며 — 업로드되거나 동기화되지 않고, 확장 프로그램을 삭제하면 함께 제거됩니다. DeepL, Azure, LibreTranslate를 위해 입력한 API 키는 브라우저에 로컬로 저장되며, 사용자가 요청을 보낼 때 해당 제공자의 서버로만 전송되고 그 외에는 어디로도 전송되지 않습니다.
