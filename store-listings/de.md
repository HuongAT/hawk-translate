Hawk Translate ist ein schneller, ablenkungsfreier Übersetzungs- und Sprachlernbegleiter für Edge. Markieren Sie beliebigen Text auf einer beliebigen Website und Sie erhalten eine sofortige Übersetzung, eine Aussprache mit natürlicher Stimme und — bei einzelnen Wörtern — Grammatik und Synonyme, um Ihren Wortschatz zu erweitern.

Was Sie tun können
Auswählen und übersetzen. Markieren Sie Text; eine kompakte Sprechblase zeigt die Übersetzung direkt neben Ihrer Auswahl.
Anhören. Klicken Sie auf das Lautsprechersymbol 🔊, um das Original oder die Übersetzung mit natürlicher Stimme zu hören. Klicken Sie zweimal auf denselben Text für eine langsamere Wiedergabe — ideal zum Üben der Aussprache.
Vokabeln lernen. Wenn Sie ein einzelnes Wort auswählen, zeigt Hawk die Wortart (Substantiv / Verb / Adjektiv …) und Synonyme an, damit Sie die gesamte Wortfamilie auf einen Blick sehen.
Volltext-Popup. Klicken Sie auf das Symbol in der Symbolleiste, um beliebigen Text einzugeben oder einzufügen, Ihre Zielsprache auszuwählen und zu übersetzen.
Kontextmenü. Übersetzen Sie jede Auswahl per Rechtsklick — ohne lange Mauswege.
Mehrere Übersetzungs-Backends — kein Schlüssel erforderlich
Hawk Translate funktioniert ohne Einrichtung sofort nach der Installation. Wählen Sie Ihren bevorzugten Dienst in den Optionen:

Google — kostenlos, Standard, schnell, hohe Qualität
MyMemory — kostenlos, kein Schlüssel, ~5.000 Wörter pro Tag
DeepL — eigener kostenloser Schlüssel (500.000 Zeichen/Monat)
Microsoft Azure Translator — eigener kostenloser Schlüssel (2 Mio. Zeichen/Monat)
LibreTranslate — Open Source; eigener Endpunkt konfigurierbar
Wenn das gewählte Backend fehlschlägt, versucht eine integrierte „Mit … erneut versuchen"-Auswahl es sofort mit einem anderen Anbieter — ohne Umweg über die Einstellungen.

Ihre Einstellungen
Thema: Automatisch / Hell / Dunkel für Popup und Sprechblase.
Sprechblasen-Stil: Klassisch (kompakt) oder Karte (Original und Übersetzung, jeweils mit eigenem Lautsprecher).
Auto-Schließen: Die Sprechblase schließt sich nach einigen Sekunden selbst — bewegen Sie den Mauszeiger darüber, um zu pausieren. Konfigurierbar von 0 (aus) bis 120 Sekunden.
Wann die Sprechblase angezeigt wird: ein kleines Falkensymbol zum Anklicken, sofort bei Auswahl oder nur über Popup / Rechtsklick.

Erweiterungs-Metadaten in 20 Sprachen lokalisiert.

Datenschutz
Hawk Translate erhebt oder übermittelt keine persönlichen Daten an den Entwickler. Der von Ihnen übersetzte Text wird nur an den von Ihnen gewählten Anbieter gesendet (Google, MyMemory, DeepL, Azure oder LibreTranslate). API-Schlüssel, die Sie für DeepL, Azure oder LibreTranslate eingeben, werden lokal in Ihrem Browser gespeichert und niemals an andere Stellen übertragen als an die Server des jeweiligen Anbieters für die von Ihnen ausgelösten Anfragen.
