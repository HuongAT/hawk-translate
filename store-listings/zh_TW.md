Hawk Translate 是 Edge 上一款快速、零干擾的翻譯與語言學習小幫手。在任何網站上反白任何文字，即可獲得即時翻譯、自然語音的發音；針對單一單字，還會顯示文法與同義詞，協助你擴充字彙。

你可以做什麼
反白翻譯。反白文字後，緊鄰選取範圍會出現一個精簡的氣泡顯示翻譯。
聆聽。按下🔊喇叭即可用自然語音聽到原文或譯文。在同一段文字按兩下，會以較慢的速度重複——非常適合練習發音。
學習字彙。當你只選擇一個單字時，Hawk 會顯示詞性（名詞 / 動詞 / 形容詞……）與同義詞，讓你一眼看到整個詞族。
全文彈出視窗。按下工具列圖示，可輸入或貼上任意文字，選擇目標語言後翻譯。
右鍵選單。任意選取都可用右鍵直接翻譯——不必大幅移動滑鼠。
多個翻譯後端 — 不需金鑰
Hawk Translate 開箱即用，零設定。在「選項」中選擇你偏好的服務：

Google — 免費、預設、快速、高品質
MyMemory — 免費、無需金鑰，每天約 5,000 個字
DeepL — 自備免費金鑰（每月 50 萬字元）
Microsoft Azure Translator — 自備免費金鑰（每月 200 萬字元）
LibreTranslate — 開源；可設定自己的端點
若所選後端失敗，內嵌的「以其他服務重試」選擇器會立即切換到另一家供應商再試——不必進入設定。

為語言學習者設計
原文與譯文都附有喇叭，讓你既能理解也能聆聽來源語言。
「詞族」面板呈現細微差異：依詞性分組的同義詞，比平鋪直敘的翻譯更快地建立字彙。
精簡、專注、不擋路的介面。
你的控制項
主題：自動 / 淺色 / 深色，適用於彈出視窗與氣泡。
氣泡樣式：經典（精簡）或卡片（原文與譯文各自附喇叭）。
自動關閉：氣泡會在數秒後自動關閉——將滑鼠移上去可暫停。可設定為 0（停用）到 120 秒。
氣泡顯示時機：先點擊一個小老鷹圖示、選取時立即顯示，或只透過彈出視窗／右鍵顯示。
支援的語言
50 多種翻譯語言，包括英文、西班牙文、法文、德文、義大利文、葡萄牙文、俄文、日文、韓文、中文（簡體與繁體）、阿拉伯文、印地文、越南文、泰文、土耳其文、印尼文、烏克蘭文、波蘭文、荷蘭文等。擴充功能的中介資料已在地化為 20 種語言。

隱私
Hawk Translate 不會向開發者收集或傳送任何個人資料。你翻譯的文字僅會傳送至你所選擇的供應商（Google、MyMemory、DeepL、Azure 或 LibreTranslate）。你為 DeepL、Azure 或 LibreTranslate 輸入的 API 金鑰會本機儲存在瀏覽器中，且僅在你發起請求時傳送到該供應商自己的伺服器，不會傳送到其他任何地方。
