Hawk Translate 是一款快速、零干擾的翻譯與語言學習小幫手。在任何網站上反白任何文字，即可獲得即時翻譯、自然語音的發音，若選取的是單一單字，還會顯示文法與同義詞，協助你擴充字彙。使用 YouTube、Netflix 與 Prime Video 時，可同時顯示兩種字幕語言。將想學的單字收藏起來，透過內建字卡學習。

你可以做什麼
使用 YouTube、Netflix 與 Prime Video 時可觀看雙語字幕。播放器新增的按鈕可同時顯示兩行字幕——上方是影片原本的語言，下方是你的語言。在 YouTube 上，兩行字幕都來自 YouTube 本身的字幕（包括 YouTube 的自動翻譯），並會逐行保持同步。在 Netflix 與 Prime Video 上，你可以配對該片名自帶的兩種字幕語言（時間軸完全準確，資料不會離開網頁）、用你選擇的翻譯供應商將原始字幕機器翻譯成你的語言，或是為只有單一語言字幕的片名載入你自己的字幕檔（.srt、.vtt、.ttml）。機器翻譯的字幕會逐步顯示，並依片名快取，重看時不會重新翻譯。在含廣告的 Prime 串流中，字幕在廣告插播前後也會保持同步。字幕行可隨時調整大小，你選擇的語言組合會被記住，下一部影片會自動套用。暫停播放並選取任一字幕單字即可翻譯或用 ☆ 收藏——字幕就此成為學習教材。
反白翻譯。反白文字後，緊鄰選取範圍會出現一個精簡的氣泡顯示翻譯。
聆聽。按下🔊喇叭即可用自然語音聽到原文或譯文。在同一段文字按兩下，會以較慢的速度重複——非常適合練習發音。
學習字彙。當你只選擇一個單字時，Hawk 會顯示詞性（名詞 / 動詞 / 形容詞……）與同義詞，讓你一眼看到整個詞族。
儲存單字並以字卡複習。點選任何翻譯旁的 ☆，即可將它加入學習清單。以間隔重複排程複習你的單字：已經熟悉的單字出現頻率會逐漸降低，答錯的單字會很快再次出現，而已經精通的單字則會從輪替中畢業。你可以隨時將清單匯出為 Anki、CSV 或 JSON。
保留本機記錄。每一次翻譯都會儲存在你的裝置上——可搜尋、可依網站與日期篩選，也可以匯出。保留時間由你決定，也可以完全關閉。
全文彈出視窗。按下工具列圖示，可輸入或貼上任意文字，選擇目標語言後翻譯。
右鍵選單。任意選取都可用右鍵直接翻譯——不必大幅移動滑鼠。
鍵盤快捷鍵。指定一個快捷鍵，即可立即翻譯目前選取的文字，即使在你已關閉氣泡的頁面上也適用。
翻譯 PDF。選擇啟用後，網頁上的 PDF 會在內建檢視器中開啟，讓選取翻譯功能在 PDF 頁面上也能像一般網頁一樣使用。

多個翻譯後端 — 不需金鑰
Hawk Translate 開箱即用，零設定。在「選項」中選擇你偏好的服務：

Google — 免費、預設、快速、高品質
MyMemory — 免費、無需金鑰，每天約 5,000 個字
DeepL — 自備金鑰（免費或付費方案）
Microsoft Azure Translator — 自備免費金鑰（每月 200 萬字元）
LibreTranslate — 開源；可指向你自己的端點
若所選後端失敗，內建的「以其他服務重試」選擇器會立即切換到另一家供應商再試——不必繞道進入設定。

為語言學習者設計
YouTube、Netflix 與 Prime Video 上的雙語字幕，能把任何有字幕的影片變成聽力練習：聆聽原文、同時閱讀兩種語言，並在不離開播放器的情況下收藏不懂的單字。
原文與譯文都附有喇叭，讓你在閱讀意思的同時，也能聽到原始語言的發音。
「詞族」面板呈現細微差異：依詞性分組的同義詞，比單純的翻譯更快建立字彙量。
字卡複習能把你瀏覽時實際遇到的單字，轉化為長期記憶中的字彙——不需要另外的應用程式，也不需要帳號。
精簡、專注、不擋路的介面。

你的設定
主題：自動 / 淺色 / 深色，適用於彈出視窗與氣泡。
氣泡樣式：經典（精簡）或卡片（原文與譯文各自附喇叭）。
自動關閉：氣泡會在數秒後自動關閉——將滑鼠移上去可暫停顯示。可設定為 0（停用）到 120 秒。
氣泡顯示時機：可選擇點擊小老鷹圖示才顯示、選取文字後立即顯示，或只透過彈出視窗／右鍵選單顯示。
個別網站設定：可直接透過右鍵選單，在你不想使用氣泡的網站上將它停用。

支援的語言
50 多種翻譯語言，包括英文、西班牙文、法文、德文、義大利文、葡萄牙文、俄文、日文、韓文、中文（簡體與繁體）、阿拉伯文、印地文、越南文、泰文、土耳其文、印尼文、烏克蘭文、波蘭文、荷蘭文等。擴充功能的中介資料已在地化為 20 種語言。

隱私
Hawk Translate 不會向開發者收集或傳送任何個人資料。你翻譯的文字僅會傳送至你所選擇的供應商（Google、MyMemory、DeepL、Azure 或 LibreTranslate）。雙語字幕讀取的是 YouTube、Netflix 或 Prime Video 針對你正在觀看的影片本來就會提供的字幕；當兩行字幕都來自該影片本身的字幕軌時，不會用到任何翻譯供應商，這些資料也不會離開你的瀏覽器。如果你在 Netflix 或 Prime Video 上選擇機器翻譯選項，字幕文字會被傳送到你所選擇的翻譯供應商——就像其他翻譯一樣——翻譯結果只會快取在你的裝置上。你的翻譯記錄、收藏的單字與字卡複習進度都只儲存在你的裝置上——不會上傳、不會同步，解除安裝後也會一併移除。你為 DeepL、Azure 或 LibreTranslate 輸入的 API 金鑰會儲存在瀏覽器本機，且僅在你發起請求時傳送到該供應商自己的伺服器，不會傳送到其他任何地方。
