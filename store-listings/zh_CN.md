Hawk Translate 是一款快速、零干扰的翻译与语言学习伴侣。在任意网站上选中任何文本，即可获得即时翻译、自然语音的发音；如果只选中单个单词，还会显示语法和同义词，帮助你扩展词汇。看 YouTube、Netflix 和 Prime Video 视频时，可以同时显示两种语言的字幕。保存你想记住的单词，并通过内置闪卡功能来学习它们。

你可以做什么
双语字幕观看 YouTube、Netflix 和 Prime Video。播放器中新增的按钮可以同时显示两行字幕——上方是视频原声语言，下方是你的目标语言。在 YouTube 上，两行字幕均来自 YouTube 自带的字幕（包括 YouTube 的自动翻译），并逐行保持同步。在 Netflix 和 Prime Video 上，你可以搭配片源自带的两种字幕语言（时间轴完全精准，数据不离开页面），也可以用你选择的翻译服务将原始字幕机器翻译成你的语言，或者为只有一种语言字幕的片源加载自己的字幕文件（.srt、.vtt、.ttml）。机器翻译的字幕会逐步生成并按片源缓存，因此重新观看时不会重复翻译。在含广告的 Prime 视频流中，字幕在广告间隔前后也能保持同步。字幕行可以随时调整大小，你选择的语言组合会被记住，并在下一个视频中自动应用。暂停视频并选中任意字幕单词即可翻译或用☆收藏——字幕从此变成学习素材。
划词翻译。选中文本后，紧邻你的选区会出现一个紧凑的气泡，显示翻译结果。
聆听。点击🔊扬声器，即可用自然语音收听原文或译文。在同一段文本上再次点击可获得较慢语速的重复播放——非常适合练习发音。
学习词汇。选中单个单词，Hawk 会显示它的词性（名词 / 动词 / 形容词……）以及同义词，让你一眼看到整个词族。
保存单词并以闪卡形式复习。点击任意翻译上的☆即可将其加入学习列表。系统会按照间隔重复的节奏安排复习：你掌握得好的单词出现频率会越来越低，答错的单词会很快再次出现，而你已经完全掌握的单词则会从复习轮换中毕业。你可以随时将学习列表导出为 Anki、CSV 或 JSON 格式。
保留本地历史记录。每一次翻译都会保存在你的设备上——可搜索、可按网站和日期筛选、可导出。你可以自行决定保留多长时间，也可以完全关闭这项功能。
全文弹窗。点击工具栏图标即可输入或粘贴任意文本，选择目标语言后翻译。
右键菜单。在右键菜单中直接翻译任意选中内容——无需大幅移动鼠标。
键盘快捷键。设置一个快捷键，即可立即翻译当前选中内容，即便在你关闭了气泡功能的页面上也同样有效。
翻译 PDF 文件。开启此选项后，网页版 PDF 会在内置查看器中打开，让划词翻译在 PDF 页面上也能像普通网页一样使用。

多个翻译后端 — 无需密钥
Hawk Translate 开箱即用，无需任何设置。在选项中选择你偏好的翻译服务：

Google — 免费、默认、快速、质量高
MyMemory — 免费、无需密钥，每天约 5,000 词
DeepL — 使用你自己的密钥（免费版或付费版）
Microsoft Azure Translator — 使用你自己的免费密钥（每月 200 万字符）
LibreTranslate — 开源软件；可指向你自己的服务端点
如果所选的后端翻译失败，内置的「换一个试试」选择器会立即切换到另一个提供商重新尝试——无需绕道设置页面。

为语言学习者设计
YouTube、Netflix 和 Prime Video 上的双语字幕，让任何带字幕的视频都变成听力练习：听原声、读双语文本，并且无需离开播放器就能收藏你不认识的单词。
原文和译文都配有扬声器，让你在阅读含义的同时，也能听到源语言的发音。
「词族」面板呈现细微差别：按词性分组查看同义词，比单纯的翻译更能快速积累词汇。
闪卡复习把你在浏览时实际遇到的单词转化为长期记忆的词汇——无需另装应用，无需注册账号。
紧凑、专注、不挡路的界面。

你的设置
主题：弹窗和气泡均支持自动 / 浅色 / 深色。
气泡样式：经典（紧凑）或卡片（原文与译文分别显示，各自带有扬声器）。
自动关闭：气泡会在几秒后自动关闭——鼠标悬停可暂停计时。可在 0（关闭）到 120 秒之间自由设置。
气泡出现时机：点击小猎鹰图标后显示、选中文本即立即显示，或仅通过弹窗 / 右键菜单显示。
按网站单独控制：直接在右键菜单中，为不想使用气泡的网站关闭该功能。

支持的语言
支持 50 多种翻译语言，包括英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、日语、韩语、中文（简体与繁体）、阿拉伯语、印地语、越南语、泰语、土耳其语、印度尼西亚语、乌克兰语、波兰语、荷兰语等。扩展的元数据已本地化为 20 种语言。

隐私
Hawk Translate 不会向开发者收集或发送任何个人数据。你要翻译的文本只会被发送给你选择的翻译服务商（Google、MyMemory、DeepL、Azure 或 LibreTranslate）。双语字幕读取的是 YouTube、Netflix 或 Prime Video 本身为你正在观看的视频提供的字幕；当两行字幕都来自视频自带的字幕轨道时，不涉及任何翻译服务商，这些数据也绝不会离开你的浏览器。如果你在 Netflix 或 Prime Video 上选择机器翻译选项，字幕文本会被发送给你选定的翻译服务商——就像其他翻译一样——翻译结果只会缓存在你的设备上。你的翻译历史、收藏的单词以及闪卡学习进度都只保存在你的设备上——不会上传，不会同步，卸载扩展后即被删除。你为 DeepL、Azure 或 LibreTranslate 输入的 API 密钥会保存在浏览器本地，除了你发起请求时发送到该服务商自己的服务器之外，绝不会发送到任何其他地方。
