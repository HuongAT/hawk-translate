Hawk Translate 是 Edge 上一款快速、零干扰的翻译与语言学习伴侣。在任意网站上高亮任何文本，即可获得即时翻译、自然语音的发音；对于单个单词，还会显示语法和同义词，帮助你扩展词汇。

你可以做什么
划词翻译。高亮文本后，紧邻你的选区会出现一个紧凑的气泡显示翻译。
聆听。点击🔊扬声器即可用自然语音收听原文或译文。在同一段文本上点击两次会以更慢的速度重复一遍——非常适合练习发音。
学习词汇。当你只选一个单词时，Hawk 会显示词性（名词 / 动词 / 形容词……）以及同义词，让你一眼看到整个词族。
全文弹窗。点击工具栏图标即可输入或粘贴任意文本，选择目标语言后翻译。
右键菜单。任意选区都可右键直接翻译——无需大幅移动鼠标。
多个翻译后端 — 无需密钥
Hawk Translate 开箱即用，零配置。在「选项」中选择你偏好的服务：

Google — 免费、默认、快速、高质量
MyMemory — 免费、无需密钥，每天约 5,000 词
DeepL — 自带免费密钥（每月 50 万字符）
Microsoft Azure Translator — 自带免费密钥（每月 200 万字符）
LibreTranslate — 开源；可配置自己的端点
若所选后端失败，内嵌的「使用其他服务重试」选择器会立刻切换到另一个提供商再次尝试——无需进入设置页。

为语言学习者设计
原文和译文都带有扬声器，让你不仅理解还能听到源语言。
「词族」面板揭示细微差别：按词性分组的同义词比平面翻译更快地构建词汇。
紧凑、专注、不挡路的界面。
你的控制项
主题：自动 / 浅色 / 深色，适用于弹窗和气泡。
气泡样式：经典（紧凑）或卡片（原文与译文各自带扬声器）。
自动关闭：气泡几秒后自行关闭——悬停可暂停。可在 0（关闭）到 120 秒之间配置。
气泡显示时机：点击一个小猎鹰图标后显示，选择时立即显示，或仅通过弹窗/右键显示。
支持的语言
50+ 种翻译语言，包括英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、日语、韩语、中文（简体与繁体）、阿拉伯语、印地语、越南语、泰语、土耳其语、印度尼西亚语、乌克兰语、波兰语、荷兰语等。扩展元数据已本地化为 20 种语言。

隐私
Hawk Translate 不会向开发者收集或发送任何个人数据。你翻译的文本仅会发送给你所选择的提供商（Google、MyMemory、DeepL、Azure 或 LibreTranslate）。你为 DeepL、Azure 或 LibreTranslate 输入的 API 密钥会本地存储在浏览器中，除了用于你发起的请求并发送到该提供商自己的服务器之外，绝不会被发送到任何其他地方。
