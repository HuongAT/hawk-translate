Hawk Translate คือเพื่อนคู่หูสำหรับการแปลและเรียนรู้ภาษาที่รวดเร็วและไม่รบกวนสมาธิ ไฮไลต์ข้อความใดก็ได้บนเว็บไซต์ใดก็ได้เพื่อรับคำแปลทันที การออกเสียงด้วยเสียงที่เป็นธรรมชาติ และสำหรับคำเดี่ยว — ข้อมูลไวยากรณ์และคำพ้องความหมายเพื่อเสริมคลังคำศัพท์ของคุณ ดู YouTube, Netflix และ Prime Video พร้อมคำบรรยายสองภาษาพร้อมกัน บันทึกคำศัพท์ที่คุณอยากจดจำและเรียนรู้ด้วยแฟลชการ์ดในตัว

สิ่งที่คุณทำได้
ดู YouTube, Netflix และ Prime Video พร้อมคำบรรยายสองภาษา ปุ่มใหม่ในตัวเล่นวิดีโอจะแสดงคำบรรยายสองบรรทัดพร้อมกัน — ภาษาของวิดีโอด้านบน ภาษาของคุณด้านล่าง บน YouTube ทั้งสองบรรทัดมาจากคำบรรยายของ YouTube เอง (รวมถึงคำแปลอัตโนมัติของ YouTube) และซิงค์กันทีละบรรทัด บน Netflix และ Prime Video คุณสามารถจับคู่คำบรรยายสองภาษาที่มีอยู่แล้วในเรื่องนั้น (จังหวะเป๊ะ ไม่มีข้อมูลใดออกจากหน้าเว็บ) แปลคำบรรยายต้นฉบับเป็นภาษาของคุณด้วยผู้ให้บริการที่คุณเลือก หรือโหลดไฟล์คำบรรยายของคุณเอง (.srt, .vtt, .ttml) สำหรับเรื่องที่มีคำบรรยายเพียงภาษาเดียว บรรทัดที่แปลด้วยเครื่องจะปรากฏขึ้นทีละส่วนและถูกแคชไว้ตามเรื่อง ทำให้การดูซ้ำไม่ต้องแปลใหม่ทุกครั้ง ในการสตรีม Prime ที่มีโฆษณา คำบรรยายจะยังคงซิงค์กันแม้จะมีช่วงโฆษณาคั่น ปรับขนาดบรรทัดได้ทันที และคู่ภาษาที่คุณเลือกจะถูกจดจำและใช้โดยอัตโนมัติในวิดีโอถัดไป หยุดชั่วคราวแล้วเลือกคำใดก็ได้ในคำบรรยายเพื่อแปลหรือกด ☆ เพื่อบันทึกไว้ — คำบรรยายก็จะกลายเป็นสื่อการเรียนรู้
เลือกและแปล ไฮไลต์ข้อความ; ฟองคำพูดขนาดกะทัดรัดจะแสดงคำแปลถัดจากข้อความที่คุณเลือกทันที
ฟัง คลิกที่ลำโพง 🔊 เพื่อฟังต้นฉบับหรือคำแปลด้วยเสียงที่เป็นธรรมชาติ คลิกสองครั้งบนข้อความเดิมเพื่อให้พูดซ้ำช้าลง — เหมาะสำหรับฝึกออกเสียง
เรียนรู้คำศัพท์ เมื่อคุณเลือกเพียงคำเดียว Hawk จะแสดงชนิดของคำ (คำนาม / คำกริยา / คำคุณศัพท์…) และคำพ้องความหมาย เพื่อให้คุณเห็นทั้งตระกูลคำในคราวเดียว
บันทึกคำศัพท์และทบทวนด้วยแฟลชการ์ด แตะ ☆ บนคำแปลใดก็ได้เพื่อเพิ่มเข้ารายการคำศัพท์ของคุณ ทบทวนคำศัพท์ตามระบบการเว้นช่วงทบทวน: คำที่คุณจำได้ดีจะเวียนมาให้ทบทวนห่างขึ้นเรื่อย ๆ คำที่คุณตอบผิดจะกลับมาให้ทบทวนทันที และคำที่คุณเชี่ยวชาญแล้วจะถูกนำออกจากรอบทบทวน ส่งออกรายการคำศัพท์เป็น Anki, CSV หรือ JSON ได้ทุกเมื่อ
เก็บประวัติไว้ในเครื่อง คำแปลทุกครั้งจะถูกบันทึกไว้ในอุปกรณ์ของคุณ — ค้นหาได้ กรองตามเว็บไซต์และวันที่ได้ และส่งออกได้ คุณเป็นผู้กำหนดว่าจะเก็บไว้นานแค่ไหน หรือจะปิดการเก็บประวัติทั้งหมดก็ได้
ป๊อปอัปข้อความเต็ม คลิกที่ไอคอนบนแถบเครื่องมือเพื่อพิมพ์หรือวางข้อความใดก็ได้ เลือกภาษาเป้าหมาย แล้วแปล
เมนูคลิกขวา แปลข้อความที่เลือกด้วยการคลิกขวา — ไม่ต้องเลื่อนเมาส์ไกล
แป้นพิมพ์ลัด กำหนดปุ่มลัดเพื่อแปลข้อความที่เลือกอยู่ได้ทันที แม้ในหน้าที่คุณปิดฟองคำพูดไว้
แปลไฟล์ PDF เปิดใช้งานเพื่อให้ไฟล์ PDF บนเว็บเปิดด้วยตัวอ่านในตัว ทำให้การเลือกข้อความเพื่อแปลใช้งานได้บนหน้า PDF เหมือนกับหน้าเว็บทั่วไป

หลายแบ็กเอนด์การแปล — ไม่ต้องใช้คีย์
Hawk Translate ใช้งานได้ทันทีโดยไม่ต้องตั้งค่า เลือกบริการที่คุณชอบในหน้า Options:

Google — ฟรี ค่าเริ่มต้น เร็ว คุณภาพสูง
MyMemory — ฟรี ไม่ต้องใช้คีย์ ~5,000 คำต่อวัน
DeepL — ใช้คีย์ของคุณเอง (แพ็กเกจฟรีหรือแบบเสียเงิน)
Microsoft Azure Translator — ใช้คีย์ฟรีของคุณเอง (2 ล้านอักขระ/เดือน)
LibreTranslate — โอเพนซอร์ส; กำหนด endpoint ของคุณเอง
หากแบ็กเอนด์ที่เลือกล้มเหลว ตัวเลือก "ลองด้วย…" ในตัวจะลองใหม่ทันทีกับผู้ให้บริการรายอื่น — ไม่ต้องไปที่หน้าตั้งค่า

ออกแบบมาสำหรับผู้เรียนภาษา
คำบรรยายสองภาษาบน YouTube, Netflix และ Prime Video เปลี่ยนวิดีโอที่มีคำบรรยายให้กลายเป็นแบบฝึกฟัง: ฟังต้นฉบับ อ่านทั้งสองภาษา และบันทึกคำศัพท์ที่คุณยังไม่รู้ได้โดยไม่ต้องออกจากตัวเล่นวิดีโอ
ลำโพงทั้งบนต้นฉบับและคำแปลทำให้คุณได้ยินภาษาต้นทางไปพร้อมกับอ่านความหมาย
แผง "ตระกูลคำ" เผยรายละเอียดที่ลึกซึ้งกว่า: การเห็นคำพ้องความหมายจัดกลุ่มตามชนิดของคำสร้างคลังคำได้เร็วกว่าคำแปลที่แบนราบ
การทบทวนด้วยแฟลชการ์ดเปลี่ยนคำศัพท์ที่คุณเจอจริงระหว่างท่องเว็บให้กลายเป็นคลังคำศัพท์ระยะยาว — ไม่ต้องใช้แอปแยก ไม่ต้องสมัครบัญชี
หน้าตาแอปกะทัดรัด มุ่งเน้น และไม่ขวางทาง

การควบคุมของคุณ
ธีม: อัตโนมัติ / สว่าง / มืด สำหรับทั้งป๊อปอัปและฟองคำพูด
สไตล์ฟองคำพูด: คลาสสิก (กะทัดรัด) หรือ การ์ด (ต้นฉบับและคำแปล แต่ละส่วนมีลำโพงของตัวเอง)
ปิดอัตโนมัติ: ฟองคำพูดจะปิดตัวเองหลังจากผ่านไปไม่กี่วินาที — ชี้เมาส์ไปที่ฟองเพื่อหยุดชั่วคราว ปรับได้ตั้งแต่ 0 (ปิด) ถึง 120 วินาที
จะแสดงฟองคำพูดเมื่อใด: ไอคอนเหยี่ยวเล็ก ๆ ที่คุณคลิก แสดงทันทีเมื่อเลือกข้อความ หรือเฉพาะผ่านป๊อปอัป / คลิกขวาเท่านั้น
ควบคุมตามเว็บไซต์: ปิดฟองคำพูดสำหรับเว็บไซต์ที่คุณไม่ต้องการใช้งานได้โดยตรงจากเมนูคลิกขวา

ภาษาที่รองรับ
รองรับการแปลกว่า 50 ภาษา รวมถึงอังกฤษ สเปน ฝรั่งเศส เยอรมัน อิตาลี โปรตุเกส รัสเซีย ญี่ปุ่น เกาหลี จีน (ตัวย่อและตัวเต็ม) อาหรับ ฮินดี เวียดนาม ไทย ตุรกี อินโดนีเซีย ยูเครน โปแลนด์ ดัตช์ และอื่น ๆ ข้อมูลเมตาของส่วนขยายแปลเป็น 20 ภาษา

ความเป็นส่วนตัว
Hawk Translate ไม่เก็บหรือส่งข้อมูลส่วนบุคคลใด ๆ ไปยังผู้พัฒนา ข้อความที่คุณแปลจะถูกส่งไปยังผู้ให้บริการที่คุณเลือกเท่านั้น (Google, MyMemory, DeepL, Azure หรือ LibreTranslate) คำบรรยายสองภาษาอ่านข้อมูลจากคำบรรยายที่ YouTube, Netflix หรือ Prime Video ให้บริการอยู่แล้วสำหรับวิดีโอที่คุณกำลังดู เมื่อทั้งสองบรรทัดมาจากคำบรรยายของวิดีโอเองทั้งคู่ จะไม่มีผู้ให้บริการแปลภาษาเข้ามาเกี่ยวข้อง และข้อมูลนั้นจะไม่ออกจากเบราว์เซอร์ของคุณเลย หากคุณเลือกใช้ตัวเลือกแปลด้วยเครื่องบน Netflix หรือ Prime Video ข้อความคำบรรยายจะถูกส่งไปยังผู้ให้บริการแปลที่คุณเลือกไว้ — เช่นเดียวกับการแปลทั่วไป — และผลลัพธ์จะถูกแคชไว้ในอุปกรณ์ของคุณเท่านั้น ประวัติการแปล คำศัพท์ที่บันทึกไว้ และความคืบหน้าของแฟลชการ์ดจะถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น — ไม่มีการอัปโหลด ไม่มีการซิงค์ และจะถูกลบหากคุณถอนการติดตั้งส่วนขยาย คีย์ API ที่คุณกรอกสำหรับ DeepL, Azure หรือ LibreTranslate จะถูกเก็บไว้ในเครื่องของคุณเองภายในเบราว์เซอร์ และจะไม่ถูกส่งไปยังที่ใดเลยนอกจากเซิร์ฟเวอร์ของผู้ให้บริการนั้น ๆ สำหรับคำขอที่คุณส่งเองเท่านั้น
