Hawk Translate — це швидкий, без зайвих відволікань помічник для перекладу та вивчення мов у Edge. Виділіть будь-який текст на будь-якому сайті і отримайте миттєвий переклад, вимову природним голосом, а для окремих слів — граматику та синоніми, щоб поповнювати словниковий запас.

Що ви можете робити
Виділяйте і перекладайте. Виділіть текст; компактна підказка показує переклад прямо поруч із вашим виділенням.
Слухайте. Натисніть на динамік 🔊, щоб почути оригінал чи переклад природним голосом. Натисніть двічі на тому самому тексті для повільнішого повтору — чудово для відпрацювання вимови.
Вчіть слова. Коли ви виділяєте одне слово, Hawk показує його частину мови (іменник / дієслово / прикметник…) і синоніми, щоб ви бачили всю родину слів одразу.
Спливаюче вікно для тексту. Натисніть піктограму на панелі інструментів, щоб ввести або вставити будь-який текст, вибрати цільову мову та перекласти.
Контекстне меню. Перекладайте будь-яке виділення правою кнопкою миші — без зайвих рухів.
Декілька рушіїв перекладу — ключ не потрібен
Hawk Translate працює одразу після встановлення без жодних налаштувань. Оберіть улюблений сервіс у Параметрах:

Google — безкоштовно, типово, швидко, висока якість
MyMemory — безкоштовно, без ключа, ~5 000 слів на день
DeepL — ваш власний безкоштовний ключ (500 тис. символів/міс)
Microsoft Azure Translator — ваш власний безкоштовний ключ (2 млн символів/міс)
LibreTranslate — з відкритим кодом; налаштуйте власний endpoint
Якщо обраний рушій не спрацює, вбудований вибір «Спробувати з…» миттєво повторить запит у іншого провайдера — без походу в налаштування.

Створено для тих, хто вчить мови
Динамік і на оригіналі, і на перекладі дозволяє не лише розуміти, а й чути мову-джерело.
Панель Родини слів відкриває нюанси: синоніми, згруповані за частинами мови, нарощують словниковий запас швидше, ніж простий переклад.
Компактний, зосереджений інтерфейс, який не заважає.
Ваші налаштування
Тема: Автоматично / Світла / Темна для спливаючого вікна і підказки.
Стиль підказки: Класичний (компактний) або Картка (оригінал і переклад, кожен зі своїм динаміком).
Автоматичне закриття: підказка зникає сама за кілька секунд — наведіть курсор, щоб призупинити. Налаштовується від 0 (вимк.) до 120 секунд.
Коли показувати підказку: маленька піктограма яструба для натискання, миттєво при виділенні або лише через спливаюче вікно / правий клік.
Підтримувані мови
Понад 50 мов перекладу, серед яких англійська, іспанська, французька, німецька, італійська, португальська, російська, японська, корейська, китайська (спрощена та традиційна), арабська, гінді, в'єтнамська, тайська, турецька, індонезійська, українська, польська, нідерландська та інші. Метадані розширення локалізовано 20 мовами.

Приватність
Hawk Translate не збирає і не передає розробникові жодних персональних даних. Текст, який ви перекладаєте, надсилається лише обраному вами провайдеру (Google, MyMemory, DeepL, Azure або LibreTranslate). API-ключі, які ви вводите для DeepL, Azure або LibreTranslate, зберігаються локально у вашому браузері і ніколи не передаються нікуди, окрім серверів відповідного провайдера для запитів, які ви робите.
