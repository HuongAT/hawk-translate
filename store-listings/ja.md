Hawk Translate は、Edge 向けの高速で気が散らない翻訳・語学学習のお供です。任意のウェブサイトの任意のテキストをハイライトすると、即座に翻訳、自然な声での発音、そして単語ひとつであれば語彙を広げるための品詞情報と類義語が手に入ります。

できること
選択して翻訳。テキストをハイライトすると、選択範囲のすぐ隣にコンパクトなバブルで翻訳が表示されます。
聞く。🔊 スピーカーをクリックすると、原文または翻訳を自然な声で聞けます。同じテキストを2回クリックするとゆっくり再生され、発音練習に最適です。
語彙を学ぶ。単語を1つだけ選択すると、Hawk が品詞（名詞 / 動詞 / 形容詞…）と類義語を表示し、単語ファミリー全体をひと目で確認できます。
全文ポップアップ。ツールバーのアイコンをクリックして任意のテキストを入力または貼り付け、対象言語を選んで翻訳します。
右クリックメニュー。任意の選択を右クリックで翻訳 — マウスを大きく動かす必要はありません。
複数の翻訳バックエンド — キー不要
Hawk Translate は設定なしですぐに動作します。「オプション」でお好みのサービスを選んでください：

Google — 無料、デフォルト、高速、高品質
MyMemory — 無料、キー不要、1日約5,000語
DeepL — 自分の無料キーを利用（月50万文字）
Microsoft Azure Translator — 自分の無料キーを利用（月200万文字）
LibreTranslate — オープンソース。独自のエンドポイントを設定可能
選択したバックエンドが失敗した場合は、組み込みの「これで試す…」セレクタが、設定画面を開かずに別のプロバイダーで即座に再試行します。

語学学習者のために設計
原文と翻訳の両方にスピーカーがあるため、ソース言語を理解するだけでなく聞くこともできます。
「単語ファミリー」パネルはニュアンスを示します。品詞ごとにまとめられた類義語を眺める方が、平坦な翻訳よりも語彙が早く身につきます。
邪魔にならないコンパクトで集中したUI。
あなたのコントロール
テーマ：自動 / ライト / ダーク（ポップアップとバブル両方）。
バブルのスタイル：クラシック（コンパクト）またはカード（原文と翻訳の両方にそれぞれスピーカー）。
自動クローズ：バブルは数秒後に自動で消えます — ホバーで一時停止可能。0（オフ）から120秒まで設定できます。
バブルの表示タイミング：クリックする小さなホークのアイコン／選択時に即時／ポップアップまたは右クリックのみ。
対応言語
50以上の翻訳言語に対応：英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、日本語、韓国語、中国語（簡体字・繁体字）、アラビア語、ヒンディー語、ベトナム語、タイ語、トルコ語、インドネシア語、ウクライナ語、ポーランド語、オランダ語ほか多数。拡張機能のメタデータは20言語にローカライズされています。

プライバシー
Hawk Translate は、開発者に個人データを収集または送信することはありません。翻訳するテキストは、あなたが選んだプロバイダー（Google、MyMemory、DeepL、Azure、LibreTranslate）にのみ送信されます。DeepL、Azure、LibreTranslate 用に入力した API キーはブラウザ内にローカル保存され、あなたが行うリクエストのために、そのプロバイダー自身のサーバー以外には送信されません。
