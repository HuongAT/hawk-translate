Hawk Translate は、高速で気が散らない翻訳・語学学習のお供です。任意のウェブサイトの任意のテキストを選択するだけで、即座に翻訳、自然な声での発音、そして単語ひとつであれば語彙を広げるための品詞情報と類義語が手に入ります。YouTube、Netflix、Prime Video を2つの字幕言語で同時に楽しめます。残しておきたい単語を保存し、内蔵のフラッシュカードで学習できます。

できること
2言語字幕で YouTube、Netflix、Prime Video を視聴。プレーヤーに追加された新しいボタンで、動画の言語を上段、あなたの言語を下段に、2行の字幕を同時に表示します。YouTube では、両方の行が YouTube 自体の字幕（YouTube の自動翻訳を含む）から取得され、行単位で同期したまま保たれます。Netflix と Prime Video では、その作品にもとから用意されている2つの字幕言語を組み合わせる（タイミングが完璧で、データが外部に送信されることもありません）、選んだプロバイダーで元の字幕をあなたの言語に機械翻訳する、あるいは1言語しか用意されていない作品では自分で用意した字幕ファイル（.srt、.vtt、.ttml）を読み込む、という方法が選べます。機械翻訳された行は少しずつ表示されてタイトルごとにキャッシュされるため、再視聴時に翻訳し直されることはありません。広告付きの Prime ストリームでも、広告の前後で字幕の同期がずれません。字幕の行はその場でサイズを変更でき、選んだ言語の組み合わせは記憶されて次の動画でも自動的に適用されます。一時停止して字幕中の単語を選択すれば翻訳したり ☆ で保存したりでき、字幕がそのまま学習教材になります。
選択して翻訳。テキストをハイライトすると、選択範囲のすぐ隣にコンパクトなバブルで翻訳が表示されます。
聞く。🔊 スピーカーをクリックすると、原文または翻訳を自然な声で聞けます。同じテキストを2回クリックするとゆっくり再生され、発音練習に最適です。
語彙を学ぶ。単語を1つだけ選択すると、Hawk が品詞（名詞 / 動詞 / 形容詞…）と類義語を表示し、単語ファミリー全体をひと目で確認できます。
単語を保存してフラッシュカードで復習。翻訳結果の ☆ をタップすると学習リストに追加されます。単語は間隔反復方式で復習でき、覚えている単語ほど出題間隔が長くなり、間違えた単語はすぐに出題され、習得した単語はローテーションから卒業していきます。学習リストはいつでも Anki、CSV、JSON にエクスポートできます。
ローカルに履歴を保存。すべての翻訳はお使いの端末に保存され、検索やサイト・日付での絞り込み、エクスポートが可能です。保存期間は自分で決められ、履歴機能自体をオフにすることもできます。
全文ポップアップ。ツールバーのアイコンをクリックして任意のテキストを入力または貼り付け、対象言語を選んで翻訳します。
右クリックメニュー。任意の選択を右クリックで翻訳 — マウスを大きく動かす必要はありません。
キーボードショートカット。ホットキーを割り当てれば、バブルをオフにしたページでも、選択中のテキストを即座に翻訳できます。
PDF を翻訳。設定を有効にすると、ウェブ上の PDF が内蔵ビューアーで開かれるようになり、通常のウェブページと同じように PDF 上でも選択して翻訳できます。

複数の翻訳バックエンド — キー不要
Hawk Translate は設定なしですぐに動作します。「オプション」でお好みのサービスを選んでください：

Google — 無料、デフォルト、高速、高品質
MyMemory — 無料、キー不要、1日約5,000語
DeepL — 自分のキーを利用（無料プランまたは有料プラン）
Microsoft Azure Translator — 自分の無料キーを利用（月200万文字）
LibreTranslate — オープンソース。独自のエンドポイントを設定可能
選択したバックエンドが失敗した場合は、組み込みの「これで試す…」セレクタが、設定画面を開かずに別のプロバイダーで即座に再試行します。

語学学習者のために設計
YouTube、Netflix、Prime Video の2言語字幕は、字幕付きの動画をそのままリスニング教材に変えます。原文の音声を聞きながら両方の言語を読み、プレーヤーから離れることなく知らない単語を保存できます。
原文と翻訳の両方にスピーカーが付いているので、意味を読みながら原語の発音を聞くことができます。
「単語ファミリー」パネルはニュアンスを示します。品詞ごとにまとめられた類義語を眺める方が、平坦な翻訳よりも語彙が早く身につきます。
フラッシュカードでの復習は、閲覧中に実際に出会った単語を長期的な語彙力に変えます — 別のアプリもアカウントも不要です。
邪魔にならないコンパクトで集中したUI。

設定
テーマ：自動 / ライト / ダーク（ポップアップとバブル両方）。
バブルのスタイル：クラシック（コンパクト）またはカード（原文と翻訳の両方にそれぞれスピーカー）。
自動クローズ：バブルは数秒後に自動で消えます — ホバーで一時停止可能。0（オフ）から120秒まで設定できます。
バブルの表示タイミング：クリックする小さなホークのアイコン／選択時に即時／ポップアップまたは右クリックのみ。
サイトごとの制御：右クリックメニューから、バブルを表示したくないサイトで直接無効にできます。

対応言語
50以上の翻訳言語に対応：英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、日本語、韓国語、中国語（簡体字・繁体字）、アラビア語、ヒンディー語、ベトナム語、タイ語、トルコ語、インドネシア語、ウクライナ語、ポーランド語、オランダ語ほか多数。拡張機能のメタデータは20言語にローカライズされています。

プライバシー
Hawk Translate は、開発者に個人データを収集または送信することはありません。翻訳するテキストは、あなたが選んだプロバイダー（Google、MyMemory、DeepL、Azure、LibreTranslate のいずれか）にのみ送信されます。2言語字幕は、視聴中の動画に対して YouTube、Netflix、Prime Video がもともと提供している字幕データを読み取ります。両方の行が動画自体の字幕トラックから取得される場合は、翻訳プロバイダーは一切関与せず、そのデータがブラウザの外に送信されることもありません。Netflix や Prime Video で機械翻訳オプションを選んだ場合は、他の翻訳と同様に、字幕テキストが選択した翻訳プロバイダーに送信され、結果はお使いの端末にのみキャッシュされます。翻訳履歴、保存した単語、フラッシュカードの学習進捗はお使いの端末にのみ保存され、アップロードや同期は行われず、拡張機能をアンインストールすると削除されます。DeepL、Azure、LibreTranslate 用に入力した API キーはブラウザ内にローカル保存され、あなたが行うリクエストのために、そのプロバイダー自身のサーバー以外には送信されません。
